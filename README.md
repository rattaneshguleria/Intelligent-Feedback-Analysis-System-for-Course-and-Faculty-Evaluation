# Intelligent Feedback Analysis System for Course and Faculty Evaluation
Project ID: CSEAIML2026-P38 (backend complete)

Ingests open-ended student feedback, removes identifying information, groups comments into
themes, scores sentiment per clause, and produces privacy-safe insight reports, semester
trends and an accuracy evaluation. Full detail: [docs/TECHNICAL_DOCUMENTATION.md](docs/TECHNICAL_DOCUMENTATION.md).

## Run it (from `backend/`)
```bash
pip install -r requirements.txt
python -m unittest discover -s tests -t . -v      # 55 tests
bash scripts/demo.sh                              # full pipeline on synthetic data
uvicorn app.main:app --reload                     # API docs at http://localhost:8000/docs
```

Step by step:
```bash
python scripts/generate_synthetic.py
python -m app.cli init
python -m app.cli load-reference ../data/synthetic
python -m app.cli ingest ../data/synthetic/feedback_raw.csv
python -m app.cli analyze --topics keyword --sentiment lexicon
python -m app.cli report faculty F02                      # also: offering ID | course CSE201 | department CSE
python -m app.cli trends faculty F02
python -m app.cli compare --group-by faculty --semester 2026-Spring
python -m app.cli export-reports --out ../docs/sample_reports
python -m app.cli evaluate
```

Set `FEEDBACK_SALT` in production. In development a random salt is created in `data/.salt`
(git-ignored).

## Using the main methods (BERTopic and transformer sentiment)
```bash
pip install bertopic sentence-transformers umap-learn hdbscan transformers torch
python -m app.cli analyze --topics bertopic --sentiment transformer
python -m app.cli evaluate        # compares every method's newest run
```
Reports automatically prefer BERTopic over keyword over LDA, and transformer over VADER over
lexicon. Override with `--theme-run N --sentiment-run N`.

## Evaluating on real feedback
Synthetic accuracy is an upper bound. For a defensible number:
```bash
python -m app.cli export-sample --n 300          # writes data/annotation_sample.csv
# hand-fill gold_theme and gold_sentiment, then:
python -m app.cli evaluate --labels ../data/annotation_sample.csv
```
